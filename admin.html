Users & Roles

How access is split, per the Phase 1 blueprint.

👑 Super Admin

Full system control.

  • ✅ Everything a Catalog Manager can do
  • ✅ Site settings (WhatsApp number, hero banners)
  • ✅ User & role management
  • ✅ Full enquiry reporting

🗂️ Catalog Manager

Cataloguing only.

  • ✅ Create, edit, publish products
  • ✅ Manage collections
  • 🚫 No access to site settings
  • 🚫 No access to user/role management

How to add a team member

This is now real, server-enforced access — the role lives in the profiles table and Row Level Security checks it on every request, so it can't be bypassed from the browser. To add someone: Supabase dashboard → Authentication → Users → Add user (creates them as Catalog Manager automatically) — then, to make them Super Admin, run update public.profiles set role='super_admin' where email='them@example.com'; in the SQL editor. There's no invite/remove UI here yet — that's the next thing worth building if you get more than one or two admins.

Bulk Upload Products (CSV)

✕

Upload a CSV to add or update many products at once. Rows with an existing product name are updated in place; new names create new products. Download a starter template to see the exact column format.
